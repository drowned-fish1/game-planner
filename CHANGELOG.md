# Changelog

Notable user-facing and maintainer-facing changes are recorded here. The project follows semantic versioning while it approaches a stable 1.0 release.

## 0.6.0 - 2026-08-02

### Added

- Automated tests for AI service behavior, board geometry, room connections, collaboration lifecycle, storage recovery, and themes.
- Atomic desktop storage, rolling backups, corruption recovery, and manual restore safeguards.
- Chinese/English localization foundations and runtime language switching.
- Command palette, shortcut help, improved keyboard accessibility, and light theme support.
- Multi-select, marquee selection, group movement, and alignment snapping on the brainstorming board.
- Project import/export validation and safer confirmation flows.

### Improved

- LAN collaboration reconnect behavior, timeouts, snapshot refresh, and error handling.
- Responsive layouts, local font delivery, lazy-loaded modules, and production bundle size.
- Release metadata, lint rules, pre-commit checks, regression documentation, and build verification.

### Open-source maintenance

- Added the MIT license, CI workflow, contribution guide, security policy, and updated project documentation.
- Removed editor-specific state and local Copilot indexes from version control.
